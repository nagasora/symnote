# SymNote 要件定義 v0.1

## 1. 概要

- プロダクト名: SymNote
- 組織: Symbiotix
- 目的:
  - 会話 / メモ / ToDo / 予定を一元管理し、
  - AI による要約・キーワード抽出・関連アイデア・週次ふりかえりで
  - ユーザーの日々の生活と学びを豊かにする。

## 2. 対象ユーザー

- 学生: 授業・ゼミ・自習の記録と復習
- 社会人: 会議・打ち合わせ・タスク管理
- クリエイター / 起業志望: アイデア整理とブレインストーミング

共通ニーズ:
- 日々生まれる情報をためるだけでなく「整理・俯瞰・発展」させたい
- カレンダー的に1日・1週間を振り返りたい

## 3. スコープ（MVP）

### Must

- テキストからノート作成（タイトル / 本文 / タグ / 日付）
- ノートの自動要約
- キーワード抽出
- 意味検索（ベクトル類似）
- ノート一覧（ノートアプリ風 UI）
- 週 / 日単位のカレンダー一覧（簡易版）
- 週次ふりかえりノートの自動生成（ボタン起動）

### Should

- ToDo / 予定としての保存（kind区別）
- カレンダー画面から日別詳細を表示

### Out of Scope（v0.1ではやらない）

- マルチユーザー / 認証
- クラウド同期 / モバイルアプリ
- チーム共有・コラボ編集
