# SymNote 要件定義 v0.1

## 1. 概要
### 1.1 プロダクト概要
- プロダクト名: SymNote（シムノート）
- 目的:
  - 頭の中のモヤモヤ（メモ・アイデア・タスク候補）を一箇所に集約
  - AI がタスクを抽出し、重要度・緊急度に基づいて優先順位付け
  - 「今日やるべき3つ」「今週やるべき5つ」を自動提案
- コア理念: 思考から実行までの“迷い”をなくすアプリ

### 1.2 コア価値（Value Proposition）
- 圧倒的な思考整理: メモを投入すると AI が「タスク・アイデア・保留」に自動分類
- 自動優先順位付け: 重要度・緊急度・所要時間・エネルギーレベルを AI が推定
- 今日/今週の明確化: 「今日のトップ3」「今週の5つ」を提案
- 週次振り返り自動生成: 完了タスクとメモから「学び・改善・来週のフォーカス」を生成

## 2. ターゲットユーザー
- 学生（授業・研究・バイト・プライベートが混在）
- 社会人（業務タスク + 自己研鑽 + プライベートが混在）
- 個人開発者 / 起業志望（アイデア・タスクが雪だるま式）
- 共通課題:
  - メモはしても整理できず溜まる
  - タスクが多すぎて選べない
  - 今日何をすべきか決めるのに時間がかかる  
  => SymNote はこれを AI × UI で解決する。

## 3. スコープ（MVP）
### 3.1 Must（必須）
- 思考インボックス: 大きめの入力欄、何でも放り込める、タイトル不要・日付自動付与、タグ任意
- AI によるメモ整理: `task | idea | someday` + 重要度(1-5) + 緊急度(1-5) + 所要時間(短/中/長) + エネルギー(低/中/高)
- ToDo リスト & 優先順位付け: 重要度×緊急度で自動ソート、手動編集可、ステータス `未処理 | 今日 | 今週 | 完了`
- 今日/今週ビュー: 今日トップ3、今週トップ5、完了チェック

### 3.2 Should（できれば）
- 簡易カレンダー（週ビュー）: 日ごとのタスク数・メモ数一覧、日クリックで詳細
- 週次振り返り（AI）: 完了タスク + メモから「今週要約 / 良かった点 / 来週フォーカス」を生成

### 3.3 Could（後回し）
- 音声入力（Whisper）
- Google カレンダー連携
- モバイル最適化

## 4. ユーザーストーリー（抜粋）
- SN-1 インボックス入力  
  - 目的: 思いついたことを即時記録  
  - 受入: 入力後1秒以内に保存され一覧に出る
- SN-2 インボックス整理  
  - 目的: 散乱したメモを整理  
  - 受入: AI がカテゴリ分け + タスク属性自動付与
- SN-3 タスク優先順位付け  
  - 目的: やることが多すぎる  
  - 受入: AI が「今日のトップ3」を提示
- SN-4 週次振り返り  
  - 目的: 学びを振り返り次週へ活かす  
  - 受入: 1クリックで週次レポート生成

## 5. 画面仕様
1) インボックス画面（最重要）  
   - 上部: テキスト入力欄（何でも書ける）、保存ボタン（Ctrl+Enter）  
   - 下部: 今日のインボックス一覧
2) タスク整理画面  
   - 左: インボックス一覧 / 中央: AI 抽出タスク / 右: 属性編集フォーム（重要度/緊急度/所要時間）
3) 今日ビュー  
   - 今日のトップ3、その他今日タスク、完了チェック
4) 今週ビュー  
   - 今週タスク、未完タスク、「週次振り返りを生成」ボタン

## 6. データモデル
`items` テーブル（メモ・タスク共通）
```sql
items (
  id INTEGER PRIMARY KEY,
  created_at TEXT,
  date TEXT,
  kind TEXT,              -- memo | task | weekly_review
  raw_text TEXT,
  ai_category TEXT,       -- task | idea | someday
  importance INTEGER,
  urgency INTEGER,
  effort TEXT,            -- short | medium | long
  energy TEXT,            -- low | mid | high
  status TEXT,            -- inbox | today | week | done
  tags TEXT,
  embedding BLOB
);
```

## 7. AI 機能仕様
- AI-1 インボックス分類  
  - 入力: テキスト  
  - 出力: カテゴリ（task/idea/someday）、importance、urgency、effort、energy
- AI-2 今日のタスク提案  
  - 入力: 未完タスク  
  - 出力: 今日のトップ3、選定理由
- AI-3 週次振り返り  
  - 入力: 週内の完了タスク & メモ  
  - 出力: 今週の要約、良かった点、改善点、来週のフォーカス

## 8. KPI（成功指標）
- 1日インボックス追加数の中央値 >= 3
- 今日ビューを開いた日数 >= 週5
- AI が提案するタスクの完了率 >= 50%

## 9. 今後の開発ステップ（順序）
1. items テーブル作成
2. インボックス画面の実装
3. AI 分類（メモ→タスク）
4. タスク画面（優先順位付け UI）
5. 今日/今週ビュー
6. 週次ふりかえり
7. カレンダー
8. 音声入力
9. 予定管理・Google 連携
