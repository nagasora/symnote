# SymNote ビジョン：AI 時代の最強の ToDo 管理アプリ

最終更新: 2026-10-16

## 1. 解きたい問題

AI 時代は「やること」が爆発する。AI エージェントやメール・チャットから ToDo が次々に生まれ、複数のプロジェクトが同時に進む。
人間の頭（ワーキングメモリ）でそれを全部覚えて優先順位を付けるのは無理がある。
SymNote は **「覚える・選ぶ・思い出す」を人から引き取り、人は "やる" ことだけに集中できる** ことを目標にする。

## 2. 既存サービスの調査（2026-10）

| サービス | 強み | 足りないと感じる点 |
|---|---|---|
| **Addness**（アドネス） | すべての ToDo がゴールにぶら下がり「なぜ」を持つ。ゴール → チーム目標 → 今日の ToDo の分解を AI が手伝う。Claude Code / Codex / ChatGPT を MCP で接続し、AI がゴールと経緯を読んで次の一手から進める。マインドマップで発想を整理してからゴール化 | チーム・組織向けで個人には重い。有料（Focus $39/人/月）。完了の楽しさ・継続の仕掛けは弱い |
| **Motion** | AI がカレンダーへ自動で時間割を組む | 高価・ブラックボックス。計画が勝手に動き納得感が低い |
| **Sunsama** | 朝の計画・夕方の振り返りの「儀式」と、1 日の量の上限で燃え尽きを防ぐ | AI 自動化はしない方針 |
| **Akiflow** | あらゆるアプリのタスクを 1 つの受信箱に集約 | 時間割は手作業 |

## 3. SymNote の差別化（4 本柱）

1. **ゴールでつながる ToDo（Addness の個人版）**
   すべてのタスクがゴールにぶら下がり「なぜやるか」を持つ。ゴールを書けば AI が今日の最初の一歩まで分解する。
   並行する複数プロジェクトの進捗と「何日放置しているか」がひと目で分かる。マインドマップで広げたアイデアをそのままゴールにできる。
2. **秘書キャラクター（認知負荷の肩代わり）**
   朝は「今日の予定と最優先」、夜は「今日の成果と明日の最初の一手」を秘書がまとめる（Sunsama の儀式を AI が代行）。
   ホームには **"次の一手" を 1 枚だけ** 出す。頭の中をそのまま書き出せば、秘書がタスクに分けてゴールへ振り分ける。
   話しかければ追加・完了・延期をしてくれる（完了・延期は必ず確認してから）。
3. **クエスト化（続ける仕掛け）**
   完了すると「QUEST CLEAR!」演出、経験値・ゴールド・レベル・称号・実績。ゴールドは自分で決めたご褒美と交換できる。
   期限切れでも減点しない＝責めない設計で、再開しやすくする。
4. **AI が ToDo を集めてくる（承認つき）**
   ChatGPT / Claude を MCP で接続し、メールやチャットから見つけた ToDo を受信箱へ届ける。人が承認したものだけがタスクになる。
   Google カレンダーの予定から準備タスクも提案する。

加えて、ローカルファースト（データは自分の Mac、オフラインでも動く）と、AI が使えないときのルールベースの代替を全機能で保つ。

## 4. 実装済み（2026-10-16 第 2 弾）

- **AI に任せる → 進捗の書き戻し**：タスクから引き継ぎ指示書（ゴールの理由・成功の定義つき）を作り、ChatGPT / Claude / Codex に貼るだけ。AI は MCP の `report_progress` で進捗を報告し、受信箱で承認したものだけがタスク・ゴールに反映される。
- **AI 時間割**：見積もりと Google カレンダーの空きから今日のタイムラインを提案 → 承認 → カレンダーへ書き出し（取消も可能）。
- **フォーカスモード**：「今は、これだけ。」の全面表示と円形タイマー。完走で集中ボーナス、中断しても責めない。

## 5. 今後の候補

- 夕方の振り返りと週次レビュー（ゴール別の成果・放置・来週の最初の一手を秘書がまとめる）。
- スマホから使える Web 版（PWA）とホーム画面ウィジェット。
- 固定 URL（独自ドメイン）での常時接続。
