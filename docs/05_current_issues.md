# 現状と改善ロードマップ

最終更新: 2026-10-23

## 現在の実装

- SQLiteを既定に維持し、明示設定時だけPostgreSQLを利用する。利用者ごとのデータ分離、認証、CSRF対策がある。
- Web版を「きょう・マップ・依頼・じぶん」のレスポンシブ画面へ刷新した。カレンダー読み取り、集中、報酬、週次ふりかえり、たねからの計画作成を接続した。Streamlit版は既存用途のため維持する。
- AI呼び出しはGeminiとOpenAIに対応する。ClaudeとOllamaの対応は未実装。
- SQLiteの版管理マイグレーション、WAL、busy timeout、接続のclose、バックアップ処理とpytestによる回帰テストがある。
- 今回、タスク・メモ・未仕分けの削除をゴミ箱へ退避し、設定画面から復元する流れを追加した。過去に削除した項目は復元できない。
- Webをルート・機能・共通部品・APIフックに分割し、App.tsxを78行に縮小した。VitestとPlaywrightによる回帰検証を追加した。

## ゴミ箱の仕様と限界

削除時に項目の本文とメタデータを同一トランザクションで退避する。自動消去や完全削除は提供しない。復元は新しいIDで行い、既存項目を上書きしない。元のゴールが残っていれば関連付けを維持する。

削除で停止した集中・時間割、却下したAI進捗報告、報酬履歴、繰り返し規則、外部カレンダーのイベントとの関連付けは復元しない。必要なら復元後に再設定する。ゴール、ひらめきセッションとマップの削除は今回のゴミ箱の対象外。

## 残る改善

1. **外部取り込み**: 議事録ファイル、Gmail差分取り込み、Slack直接接続、重複統合。文書の取り込みボタンは対応APIを実装するまで表示しない。定期実行は未設定。
2. **Web移行の残り**: Google予定の作成・変更、時間割の全操作、秘書の外部通知、Streamlit固有操作の移行。削除前に利用確認する。
3. **利用開始とAI**: 初回設定の案内の充実、Claude/Ollama、ホスト版の運用判断。
4. **復旧**: バックアップからの画面復元、ゴール・ひらめきのゴミ箱。広範なruff修正や不要ファイル整理は別差分。

ゲーム刷新の実装対応と検証範囲は [IMPLEMENTATION.md](redesign/game/IMPLEMENTATION.md) を参照。

## 外部確認と判断が必要な項目

- 過去に漏えいしたAPIキーの失効・再発行と履歴対応の完了は未確認。現在の追跡対象に`.env`、DB、pycがないことだけでは失効の証明にならない。キーや履歴を書き換える前に対象と影響を確認する。
- ローカル実行とホスト版のどちらを他利用者向けの主経路にするかは未決定。今回はどちらにも使える共通機能を改善する。
- 実Google/SNS連携、スマホ実機、ホスト版の稼働はローカルテストとは別に検証する。
- Streamlit削除はWebの機能移行と利用確認後、了承を得て行う。
- `debug_gen.py`等の整理は用途確認後に別差分で行う。広範な自動修正・ユーザーデータ削除はこの変更に含めない。
