## 安全性と互換性

v17のゴミ箱を維持しv18を追加。入力由来の候補と計画は確認後だけ保存する。提案生成中の対象切替や閉じる操作で古い結果が混入しないよう無効化し、保存中の二重操作を防ぐ。カレンダー外部接続失敗は基本操作を妨げない。タスクの繰り返し編集は本文と同一トランザクションで更新する。

文書ファイル取り込みAPIは今回任意のため未実装で、未対応ボタンは非表示。Streamlitの廃止、Google予定の書き込み、Slack/Gmailの自動取得、ホストへのデプロイはこの差分に含まない。実機iPhone、実Google接続、実AIプロバイダーの動作確認は別途必要。

## レビュー

独立レビューを実施。報酬/休息券、計画の保存、画面移動中の非同期結果、削除表示、IME、承認エラー、既存画面の機能差を修正。最終レビュー時点で対象範囲に未解決のブロッカーなし。
