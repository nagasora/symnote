# SymNote 画面仕様 v0.1

## 1. 画面一覧

1. ホーム画面（ノート一覧 + 検索）
2. 新規ノート画面（テキスト / 将来的に音声）
3. カレンダー画面（週ビュー）
4. 設定画面

## 2. ホーム画面

- コンポーネント
  - 検索ボックス（全文 LIKE）
  - 意味検索ボックス（クエリ文字列 → 類似ノート TopK）
  - ノート一覧テーブル
    - ID / 日付 / タイトル / 要約抜粋 / タグ
  - ノートID入力 + 「開く」ボタン
- 挙動
  - 検索文字列変更で再クエリ
  - 「開く」で詳細表示（右側 or 画面下）

## 3. 新規ノート画面

- 入力項目
  - タイトル（空なら先頭行から自動生成）
  - 日付（デフォルト: 今日）
  - 種別 kind（note / todo / event）
  - 本文
  - タグ（カンマ区切り）

- オプション
  - 要約を生成（checkbox）
  - キーワードを抽出（checkbox）

- 保存ボタン押下時
  - 必須: 本文 / 日付
  - 要約 / キーワードを生成
  - 埋め込みベクトルを生成して DB に保存

## 4. カレンダー画面（週ビュー）

- 上部: 週選択（今日を含む週がデフォルト）
- 中央: 月〜日の横並びカラム
  - 各日セル:
    - 日付
    - ノート件数（📝xN）
    - ToDo件数（✅xM）
    - 予定件数（📅xK）
- 日付クリックで右ペイン:
  - その日のノート一覧
  - その日のToDo一覧
  - その日の予定一覧
  - 「この日の要約を生成」ボタン（あれば）

- 週の下部:
  - 「この週のふりかえりを作成」ボタン
    - クリック → 週次ノート生成 → 完了メッセージ + ノートID表示

## 5. 設定画面

- 現在の設定値の表示（DB_PATH / モデル名 / 要約文数など）
- `.env` を編集せよ、という説明のみ（UIで直接編集しない）
