# SymNote 画面仕様 v0.1
思考インボックスとタスク優先づけに最適化した UI 仕様

---

## 1. 画面一覧（MVP構成）
1. **インボックス画面 / InBox** — 何でも放り込む入力画面（最重要）
2. **タスク整理画面 / Task Organizer** — インボックス → タスク化 → 優先度付け
3. **今日ビュー / Today View** — 今日やるべきことトップ3 + その他
4. **今週ビュー / Weekly View** — 今週タスク + 週次振り返り生成
5. **（オプション）週カレンダー / Weekly Calendar** — 日付ごとの実行ログとメモ数を俯瞰
6. **設定画面 / Settings**

---

## 2. 画面の詳細仕様

### 2.1 インボックス画面 / InBox
**目的**  
- 頭の中にあるメモ・タスク候補をとにかく“入れる”
- 入れた瞬間に「今日何をすべきか」を準備する

**UI構成（ラフ）**
```
+----------------------------------------+
| [テキスト入力エリア]                   |
| - なんでも書ける                      |
| - タイトル不要                        |
+----------------------------------------+
| [タグ入力]（任意） | [日付=今日デフォルト]
| [保存] ボタン
| ▼ 今日インボックス一覧
| ・メモA（未分類）
| ・メモB（未分類）
| ・…
|
| [AIでインボックスを整理する] ボタン
```

**AI整理ボタン押下後の挙動**
- メモを分類: `task | idea | someday`
- task の場合: `importance, urgency, effort, energy` を自動付与

---

### 2.2 タスク整理画面 / Task Organizer
**目的**  
AIが暫定分類したタスクを、ユーザーが最終調整する場

**UI構成（ラフ）**
```
+------------------------------------------------+
| InBox（左） | AI抽出タスク（中央） | 属性編集（右）|
| ・メモ1     | ・タスク候補         | [重要度 1-5]  |
| ・メモ2     | ・タスク候補         | [緊急度 1-5]  |
| ・メモ3     | ・タスク候補         | [所要時間 短/中/長]
|             |                      | [エネルギー 低/中/高]
|             |                      | [保存]        |
+------------------------------------------------+
```

**ポイント**
- AI結果を「人間が微調整できる」設計
- `status = today | week | done` などを更新

---

### 2.3 今日ビュー / Today View
**目的**  
その日「本当にやるべきこと」を明確にする

**UI構成（ラフ）**
```
+------------------------------------------+
| 📅 今日のトップ3（AI推薦）              |
| 1. タスクX（重要度5・緊急度5） □/✔      |
| 2. タスクY □                            |
| 3. タスクZ □                            |
| その他今日の候補                        |
| 今日のメモ（自動抽出）                  |
| 今日の振り返り欄（テキスト）            |
+------------------------------------------+
```

---

### 2.4 今週ビュー / Weekly View
**目的**  
1週間のタスク管理と週次振り返りをまとめて実施

**UI構成（ラフ）**
```
+---------------------------------------------+
| 🌤 今週のタスク（AI推薦トップ）            |
| ・タスク1（重要度×緊急度）                 |
| ・タスク2                                  |
| 今週の残タスク                             |
| 📘 今週のメモ一覧                          |
| 🪁 週次振り返り生成（AI）ボタン             |
+---------------------------------------------+
```

---

### 2.5 週カレンダー（Optional）
**UIイメージ**
```
| Mon | Tue | Wed | Thu | Fri | Sat | Sun |
|  3  |  5  |  0  |  4  |  2  |  1  |  0  | ← タスク数
```
クリックで右側に詳細パネルを表示。

---

### 2.6 設定画面 / Settings
- OpenAI APIキー
- モデル設定
- 要約の句数
- DBパス
- バックアップ

---

## 3. 画面遷移図（簡易）
インボックス → タスク整理 → 今日ビュー → 今週ビュー  
　↘ カレンダー（週） ↘ 週次振り返り生成

---

## 4. MVP 優先度（UI側）
1. インボックス画面  
2. タスク整理画面  
3. 今日ビュー  
4. 今週ビュー  
5. カレンダー（後で OK）
