# SymNote 画面仕様 v0.2
思考インボックスとタスク優先づけに最適化した UI 仕様

---

## 1. 画面一覧（MVP構成）
1. **インボックス画面 / InBox** — 何でも放り込む入力画面（最重要）
2. **タスク整理画面 / Task Organizer** — インボックス → タスク化 → 優先度付け
3. **今日ビュー / Today View** — 今日やるべきことトップ3 + その他
4. **カレンダー / Calendar** — 月単位でタスク/メモ件数を確認
5. **アイデア整理 / Idea Organizer** — アイデアからToDo生成
6. **ドキュメント分析 / Document Analysis** — PDFからタスク抽出

---

## 2. 画面の詳細仕様

### 2.1 インボックス画面 / InBox
**目的**  
- 頭の中にあるメモ・タスク候補をとにかく“入れる”
- 入れた瞬間に「今日何をすべきか」を準備する

**UI構成（ラフ）**
```
+----------------------------------------+
| [テキスト入力エリア]                   |
| - なんでも書ける                      |
| - タイトル不要                        |
+----------------------------------------+
| [期限] ○今日 ○明日 ○カレンダー選択
| [タグ入力]（任意）
| [メモとして保存] [タスクとして保存] ボタン
|
| ▼ 今日のインボックス一覧
| ・メモA（未分類）
| ・メモB（未分類）
| ・…
|
| [AIでインボックスを整理する] ボタン
```

**AI整理ボタン押下後の挙動**
- メモを分類: `task | idea | someday`
- task の場合: `importance, urgency, effort, energy` を自動付与

---

### 2.2 タスク整理画面 / Task Organizer
**目的**  
AIが暫定分類したタスクを、ユーザーが最終調整する場

**UI構成（ラフ）**
```
+------------------------------------------------+
| 日付ごとにグルーピング表示                     |
| ▼ 2024-12-02                                   |
|   [InBox] タスク候補 ... [編集]                |
|   [InBox] タスク候補 ... [編集]                |
| ▼ 2024-12-01                                   |
|   ...                                          |
+------------------------------------------------+
```

**ポイント**
- 期限日（または作成日）順に並び、新しい日付が上に来る
- 各タスクを展開すると属性（重要度・緊急度など）を編集可能

---

### 2.3 今日ビュー / Today View
**目的**  
その日「本当にやるべきこと」を明確にする

**UI構成（ラフ）**
```
+------------------------------------------+
| 📅 今日のトップ3（AI推薦）              |
| 1. タスクX（重要度5・緊急度5） □/✔      |
|    理由: 期限が今日 / 重要度が高い      |
| 2. タスクY □                            |
| 3. タスクZ □                            |
| その他今日の候補                        |
| 🚨 期限切れタスク（赤字表示）           |
+------------------------------------------+
```

---

### 2.4 カレンダー / Calendar
**目的**  
月単位でタスク量やメモの蓄積状況を把握する

**UI構成（ラフ）**
```
| < 前月      2024年 12月      翌月 > |
| Mon | Tue | Wed | Thu | Fri | Sat | Sun |
|  1  |  2  |  3  |  4  |  5  |  6  |  7  |
| T:3 | T:5 |     | T:2 |     |     |     |
| M:1 |     |     |     |     |     |     |
```
- 日付をクリックすると、その日のタスク・メモ詳細が表示される
- 期限切れタスクがある場合はアラート表示

---

### 2.5 アイデア整理 / Idea Organizer
**目的**  
漠然としたアイデアを具体的なアクションに変換する

**UI構成（ラフ）**
```
+----------------------------------------+
| [アイデア・実現したいこと入力エリア]   |
+----------------------------------------+
| [ToDoを生成する] ボタン
|
| ▼ 生成されたToDo
| ・[追加] 具体的なタスク1
| ・[追加] 具体的なタスク2
| ...
```
